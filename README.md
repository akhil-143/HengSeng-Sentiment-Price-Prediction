# HengSeng Sentiment-Based Stock Price Prediction Project

## Project Overview

This project focuses on developing an AI-powered sentiment analysis and stock price prediction system for the Hong Kong and South Korean financial markets.

The main objective is to analyse social media discussions, financial news, investor sentiment and historical stock market data to identify market trends and predict the next price movement of selected stocks.

The project combines Natural Language Processing (NLP), Machine Learning, Deep Learning and financial technical indicators to build an experimental stock price prediction pipeline.

## Key Features

- **Social Media Sentiment Analysis:** Analyse investor discussions from platforms such as LIHKG, Telegram, Futu, Naver Finance and other relevant sources.
- **Financial News Analysis:** Collect and analyse relevant financial news using Exa.
- **Market Data Collection:** Process historical stock prices, trading volume and market indicators.
- **Sentiment Classification:** Classify text as positive, negative or neutral.
- **Stock Price Prediction:** Use machine learning and neural network models to estimate the next price.
- **Technical Indicators:** Include RSI, MACD, moving averages and volatility.
- **Data Visualisation:** Present sentiment trends, stock movements and prediction results through charts and dashboards.
- **Model Evaluation:** Evaluate predictions using MAE, RMSE and directional accuracy.

## Dataset Information

The project includes a synthetic dataset generator capable of creating 1,000 separate CSV files with more than 1 GB of combined data.

**Important:** Synthetic records are generated for testing and development. They are not actual market observations, social media posts or financial news.

Real observations must be collected separately from verified data sources before conducting real-world model evaluation.
